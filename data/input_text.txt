A connection pool maintains reusable database connections so applications can avoid creating a new connection for every request.
What is a transaction isolation level?
A transaction isolation level defines how much one concurrent database transaction can observe or interfere with another.
What is eventual consistency?
Eventual consistency means distributed replicas may temporarily differ but converge toward the same value when updates stop.
What is strong consistency?
Strong consistency means reads reflect the latest committed write according to the system's consistency guarantees.
What is replication?
Replication copies data or services across multiple locations or systems to improve availability, performance, or fault tolerance.
What is sharding?
Sharding partitions data across multiple machines or storage units so each handles only part of the overall dataset.
What is horizontal scaling?
Horizontal scaling increases capacity by adding more machines or instances to a system.
What is vertical scaling?
Vertical scaling increases capacity by giving an existing machine more computing resources.
What is a stateless service?
A stateless service does not rely on locally stored client session state between independent requests.
What is a stateful service?
A stateful service maintains information about previous interactions that affects subsequent requests.
What is a session?
A session represents a sequence of interactions between a client and a service, often associated with temporary state.
What is a cookie?
A cookie is a small piece of data stored by a web browser and associated with a website for purposes such as preferences or session management.
What is local storage?
Local storage is browser-managed persistent key-value storage that allows web applications to retain data across browser sessions.
What is a web component?
A web component is a reusable custom interface element based on standardized web platform technologies.
What is a component?
A component is a modular unit of software or user interface with a defined responsibility and interface.
What is state in software?
State is the information representing the current condition of a program, object, or system.
What is state management?
State management is the organization, storage, updating, and synchronization of application state.
What is a pure UI component?
A pure UI component renders its output based primarily on its inputs and avoids unnecessary side effects.
What is reactive programming?
Reactive programming models computation around streams of changing values and propagates updates when relevant data changes.
What is a data structure?
A data structure is a way of organizing and storing data so that operations on the data can be performed efficiently.
What is an algorithm-data structure relationship?
Algorithms define procedures for processing data, while data structures organize that data to support efficient processing.
What is computational complexity?
Computational complexity studies how the resources required by an algorithm grow with input size.
What is tractability?
A problem is considered tractable when it can generally be solved efficiently enough for practical input sizes using available computational resources.
What is an NP problem?
An NP problem is a decision problem for which a proposed solution can be verified in polynomial time by a deterministic algorithm.
What is a polynomial-time algorithm?
A polynomial-time algorithm has a worst-case running time bounded by a polynomial function of the input size.
What is a decision problem?
A decision problem is a computational problem whose answer is typically expressed as yes or no.
What is an optimization problem?
An optimization problem asks for the best solution according to a specified objective or cost function.
What is a computational model?
A computational model is an abstract representation of how computation is performed and what resources are available.
What is a finite-state machine?
A finite-state machine is a model of computation consisting of a finite set of states and transitions triggered by inputs or events.
What is a state transition?
A state transition is a change from one state to another according to defined rules and conditions.
What is a regular expression?
A regular expression is a pattern language used to describe and match sequences of text.
What is a deterministic finite automaton?
A deterministic finite automaton is a finite-state machine where each state and input symbol determine at most one next state.
What is a compiler front end?
A compiler front end analyzes source code through stages such as lexical analysis, parsing, and semantic analysis to produce an intermediate representation.
What is lexical analysis?
Lexical analysis converts source characters into tokens according to the lexical rules of a programming language.
What is syntax analysis?
Syntax analysis checks the token sequence against a language grammar and constructs a structured representation such as an abstract syntax tree.
What is semantic checking?
Semantic checking verifies meaning-related constraints such as type compatibility, declarations, and valid language constructs.
What is a programming language runtime?
A runtime provides the services and mechanisms required for a program to execute, such as memory management, libraries, or virtual machines.
What is a virtual machine?
A virtual machine is a software environment that emulates or provides an abstract computing environment in which programs can execute.
What is bytecode?
Bytecode is an intermediate instruction representation designed to be executed by a virtual machine or runtime.
What is JIT compilation?
Just-in-time compilation translates code into a lower-level representation during program execution, often using runtime information for optimization.
What is interpretation versus compilation?
Interpretation executes instructions through a runtime mechanism, while compilation transforms code into another representation before or during execution.
What is source compatibility?
Source compatibility means existing source code can continue to compile or work correctly with a newer version of an interface or library.
What is binary compatibility?
Binary compatibility means already compiled programs can continue interacting correctly with a newer version of a library or component.
What is API versioning?
API versioning manages changes to an API so clients can understand and adapt to different interface versions.
What is deprecation?
Deprecation marks functionality as discouraged or obsolete while often retaining it temporarily for compatibility.
What is backward incompatible change?
A backward incompatible change modifies behavior or interfaces in a way that can break existing clients or code.
What is a breaking change?
A breaking change is a modification that can cause existing code or clients to stop functioning correctly without adaptation.
What is semantic ambiguity?
Semantic ambiguity occurs when a construct can reasonably be interpreted in more than one meaningful way.
What is code readability?
Code readability describes how easily developers can understand the intent and behavior of source code.
What is maintainable architecture?
Maintainable architecture organizes software so that changes, testing, debugging, and extension can be performed with controlled effort.
What is extensibility?
Extensibility is the ease with which new functionality can be added without requiring major changes to existing components.
What is testability?
Testability is the degree to which software can be effectively tested in isolation and under controlled conditions.
What is reusability?
Reusability is the ability to use software components in multiple contexts without rewriting their core implementation.
What is cohesion versus coupling?
Cohesion measures how closely related responsibilities are within a component, while coupling measures dependencies between components.
What is modular design?
Modular design divides software into components with focused responsibilities and well-defined interfaces.
What is an architectural decision?
An architectural decision is a significant technical choice that affects the structure, behavior, or long-term evolution of a system.
What is a trade-off?
A trade-off occurs when improving one desirable property requires accepting a disadvantage in another property.
What is technical constraint?
A technical constraint is a limitation imposed by technology, requirements, resources, compatibility, or the operating environment.
What is a proof of correctness?
A proof of correctness is a logical argument demonstrating that an algorithm satisfies its specification for all valid inputs.
What is precondition?
A precondition is a condition that must be true before an operation or function can correctly execute.
What is postcondition?
A postcondition is a condition that should be true after an operation or function completes successfully.
What is a contract in programming?
A programming contract defines preconditions, postconditions, and invariants that specify how a component should behave.
What is design by contract?
Design by contract is a software design approach that explicitly specifies preconditions, postconditions, and invariants for components.
What is defensive validation?
Defensive validation checks assumptions about data and state before performing operations that depend on those assumptions.
What is input domain?
The input domain is the set of values or conditions that an algorithm or function accepts as valid input.
What is output domain?
The output domain is the set of values or results that an algorithm or function can produce.
What is an edge case?
An edge case is an unusual or boundary input condition that may reveal defects or unexpected behavior.
What is a corner case?
A corner case is a particularly uncommon combination of conditions that can expose implementation weaknesses.
What is a happy path?
The happy path is the expected execution scenario in which all operations succeed and inputs are valid.
What is error recovery?
Error recovery is the process of restoring controlled operation after an error or failure occurs.
What is graceful shutdown?
Graceful shutdown allows a program or service to finish necessary work and release resources before terminating.
What is resource management?
Resource management controls the acquisition, use, and release of resources such as memory, files, network connections, and locks.
What is RAII?
RAII is a resource-management technique where resource ownership is tied to object lifetime so resources are acquired and released automatically.
What is deterministic resource cleanup?
Deterministic resource cleanup releases resources at a predictable point rather than relying on an unpredictable background mechanism.
What is a file descriptor?
A file descriptor is an operating-system-managed identifier representing an open file or another I/O resource.
What is input/output?
Input/output describes communication between a program and external resources such as files, devices, networks, or users.
What is buffering?
Buffering temporarily stores data in memory so that input and output operations can be performed more efficiently.
What is streaming?
Streaming processes data progressively as it becomes available instead of requiring the entire dataset to be loaded first.
What is lazy evaluation?
Lazy evaluation delays computation until the result is actually needed.
What is eager evaluation?
Eager evaluation computes an expression or value immediately when it is encountered.
What is memoization versus caching?
Memoization stores results of function computations, while caching is a broader technique for storing reusable data to speed up future operations.
What is a pipeline?
A pipeline divides processing into sequential stages where each stage transforms or passes data to the next stage.
What is a data pipeline?
A data pipeline is a sequence of automated processing stages that collects, transforms, moves, and stores data.
What is ETL?
ETL stands for extract, transform, and load, describing a process that extracts data, transforms it, and loads it into a target system.
What is data transformation?
Data transformation converts data from one representation, structure, or format into another according to defined rules.
What is data aggregation?
Data aggregation combines multiple values or records into summarized information.
What is a data model?
A data model defines how data is structured, represented, related, and constrained within a system.
What is domain modeling?
Domain modeling represents the important concepts, relationships, and rules of a problem domain in software structures.
What is business logic?
Business logic is the set of rules and operations that implement the domain-specific behavior of an application.
What is a domain object?
A domain object represents an important concept or entity from the problem domain
